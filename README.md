# 🧩 Пятнашки 3×3

Решатель пятнашек с drag&drop и пошаговым гайдом (A*).

## Возможности
- Перетаскивание плиток мышью
- Клик по клетке → ввод числа (с авто-swap)
- ПКМ → очистить клетку
- Кнопка «🧠 Решить» — оптимальное решение через A*
- Пошаговое прохождение (◀ ▶ ▶▶)

## Скачать
Готовый `.exe`: [Releases](../../releases/latest)

## Собрать самому
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```
